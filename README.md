# Help Me Choose (C)

Command-line program that helps choose devices (phone, laptop, console, etc.) based on simple requirements.

## Requirements
- GCC or any C compiler

## Build
```bash
gcc Help_Me_Choose.c -o help-me-choose
```

## Run
```bash
./help-me-choose
```

## Data files
The program reads one of the following files (enter the filename when prompted):
- `Phone.txt`
- `Tablet.txt`
- `Laptop.txt`
- `Console.txt`
- `Printer.txt`
- `Camera.txt`
- `TV.txt`

## Notes
- Reports and slides are stored under `docs/`.
